"@spinajs/http": minor
---

New `http.routes.middlewares` configuration key (default `[]`): route middlewares mounted on every route of every controller. An entry is the class name of a type registered as `RouteMiddleware`, a `RouteMiddleware` class, or `{ service, options }` with constructor options, as `@Middleware(Class, ...options)` passes them. An entry is instantiated per route exactly as the same class in `@Middleware(Class, ...options)`, so its lifetime decides sharing: a `@NewInstance()` class keeps its own per-route state. The entries are checked at startup, before any route is built. A class also declared with `@Middleware` on the controller or route is skipped globally there, so it runs once, with the local options. Global entries run before the controller and route `@Middleware` ones, in config order; `Stage`, `isEnabled` and `onRegister` apply as for any route middleware. An unknown name, a class that is not a `RouteMiddleware` or an entry of another shape fails the startup with `InvalidOption`. `RouteTiming` is now `@Injectable(RouteMiddleware)`, so `routes: { middlewares: ['RouteTiming'] }` times every route. New export: the `GlobalRouteMiddlewareEntry` type.
