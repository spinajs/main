---
"@spinajs/client": minor
---

These emitter bugs, found by the differential parity suite that lands in the next change, are fixed: a tuple whose slots accept `undefined` did not enforce `minItems`; `safeParse` threw on a NaN in an intersection of two schemas that both pass it through (it is now refused, as the server does); the siblings of a `const` or `enum` (`type`, `minLength`, `required`) were not applied; `contains` was not applied on a node without a type; a `$ref` to a closed object next to other keywords let undeclared keys through, also inside a cyclic declaration; an own `__proto__` key skipped the `additionalProperties` schema; and a coerced infinity that a `not`, `anyOf`, `oneOf` or `if` branch left in the data was accepted, where the server refuses it. `@spinajs/client/formats` gains `ajvFinite`, `ownProtoAccepted`, `coerceIn`, `coerceLocal`, `finiteReplay` and `replayLocal` (and `ajvCoerceInPlace`, `finiteAfter`, `ReplayPlan`), which generated files import, so a generated file needs the runtime of this release. `ajvCoerce` still leaves a value that would coerce to a non-finite number as it is; `ajvCoerceInPlace` returns Ajv's own result, infinity included, for the replay. The coerced union branches and the `then` and `else` of an `if` now read the value as Ajv's coercions in the earlier branches left it, and a coerced infinity that any branch of a `not`, `anyOf`, `oneOf`, `allOf` or `if` left in the data is refused, at any depth, as the server does. A new `ZOD004` diagnostic marks where Ajv coerces a value that a later keyword reads, so a `Coerced` schema may accept more than the server.

A coerced declaration that has a `not`, `anyOf`, `oneOf`, `allOf` or `if` with a branch coercing to a number now wraps its schema in a check of the value as sent, so its `<Name>Coerced` is no longer a plain object schema: `.shape` and `z.looseObject(X.shape)` are not available on it (the generated file itself never needs them there, and nothing else in the package reads them). `ZOD005` marks a node whose replay stopped at 40 keyword levels, and `ZOD001` an object whose `propertyNames` coerces its key, which makes Ajv throw. `$merge`, `$patch` and `$data` are read as Ajv reads them.

The output of a coerced `allOf` is the value Ajv leaves in its variable after every member, so `contains`, `uniqueItems` and `patternProperties` read what the server reads. `ajvUniqueItems` takes the primitive item types and, like Ajv, skips the items of another type.

A replay that would build itself again through a recursive `$ref` is cut like one past the depth limit (`ZOD005`); `emitZod` no longer overflows the stack on a declaration whose `if` tests a `$ref` to itself. `contains` on an empty array follows Ajv inside a loop over items or keys (the first one is refused, a later one passes).
