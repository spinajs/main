One client address for authn and the http limiters. The new `AuthnRealIp` (exported) is registered over `@spinajs/http`'s `RealIp`: `req.storage.realIp` and `req.storage.proxyTrust` follow `authn.http.trustProxy`, else `http.trustProxy`, so `@RateLimit`, `http.throttle`, `@Ip()` and the same-origin and CSRF guards count the client that `@IpThrottle`, the authn services and the audit log count. An app that set only `authn.http.trustProxy` used to rate limit every client as its proxy. `ClientIp` moves to Order 2, after any `RealIp`, copies `req.storage.realIp` (the socket address when none was written) and reads no trust setting of its own; a subclass that changed the address extends `AuthnRealIp` instead. A `RealIp` registration that does not extend `AuthnRealIp` fails the boot when `authn.http.trustProxy` is set and warns otherwise (`realIpOverrideFinding`, also in `authn:check-config`). `CsrfOriginGuard` takes the own origin from the trust `RealIp` stored for the request. `@IpThrottle` and the passkey and registration routes key IPv6 clients by `authn.throttle.ipv6Prefix`, else `http.throttle.ipv6Prefix`. Loaded after `RealIp` was resolved (a socket server that started first keeps that instance), the package logs an error naming the fix: import it before the socket server starts.
