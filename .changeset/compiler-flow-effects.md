Adds `FlowTracer`, a query tracer that follows builders across calls. A builder-typed parameter is a pending builder. A call that hands a builder back unexecuted is that builder, scoped as the callee and the argument left it. A choice between builders (`?:`, `??`, `||`, `&&`) is one builder, and a builder the tracer cannot follow to a model class is read from its type. With it come the authz effect types (`AuthzEffect`, `FunctionSummary`), `builderOf`, `staticKind`, `runsQuery`, `isSystemRunAs`, `memberMarker` and `scopeOf`. They read builders, scoping, copying and system runs from markers instead of the builder class names, the list of executing members, the member names `accessible`, `unscoped` and `clone`, and the packages that declare `runAs` and `SYSTEM`: a builder is a type marked `@spinajs query`, scoping and copying are members marked `@spinajs authz-scope` and `@spinajs copy`, a system run is a member marked `@spinajs run-as` called with a principal marked `@spinajs system-principal`, and a call runs the query when any part of its result is untyped, or is no builder and can be awaited or iterated asynchronously, or when its result is an unconstrained type parameter. A member that overrides one marked `@spinajs copy` is a copy too. Models are still found as subclasses of `ModelBase` of `@spinajs/orm`, and `populate` by its name.
