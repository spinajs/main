Route middlewares can wrap the rest of the route. `RouteMiddleware` gains three optional members: `onAround(invocation, proceed)`, `onRegister(route, path, controller)` and `Stage` (`'inner'` by default). `proceed()` runs the later middlewares, the action, the error handlers and the response once. It resolves with an `IRouteOutcome` when the response finished: the captured JSON reply, plus the error the chain raised, if any. A middleware that does not call it answers the request itself. `proceed()` rejects with the new `RouteClientGone` (`beforeRoute: true` or `false`) when the client went away first. An `'outer'` middleware runs right after the policy gate, before every `'inner'` one. `onRegister` runs once for each enabled middleware when the route is mounted, and a throw fails the registration with `RouteRegistrationException`. The new `AroundMiddleware` base class gives an around-only middleware no-op hooks. `buildRouteHandlers()` now assembles the whole route chain. Existing middlewares run as before, in the same order.
