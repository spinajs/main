Row level security core for Postgres (opt-in, G17). `@AccessResource(type, { rls: true | 'partial' })` and `registerAccessResource(model, type, { rls })` mark a table. `generateRls()` renders, per table, `ENABLE` and `FORCE ROW LEVEL SECURITY`, one `CREATE POLICY spina_<type>_<action>` for SELECT (`<type>:read`), UPDATE (`<type>:update`) and DELETE (`<type>:delete`), a permissive INSERT policy (inserts stay the application's to gate), and with a bypass role a `spina_<type>_bypass` policy that honours `spina.bypass = 'on'` for that role only. Each policy is the permission's list plan for any principal: an `RlsPlanSource` per model gives the plan, `PlanTermCompiler.renderSql(args, ctx)` renders each term with the principal read from the session settings `spina.subject_keys` and `spina.principal` (unset: no row). A model or term the database cannot evaluate fails with `AUTHZ020` under `rls: true`; under `'partial'` a permit member becomes TRUE and an exclusion operand is dropped, each listed in `AUTHZ021`, so the policy is never narrower than `.accessible()`. `relation.owner`, `relation.self` and `relation.column` render; `rlsMigrationSource()` writes the migration file.
