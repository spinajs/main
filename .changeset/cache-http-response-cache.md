`@ResponseCache({ ttl, scope, sharedBecause, vary, tags, cache })` stores the JSON reply of a GET route in a named cache of `@spinajs/cache` and answers later requests with the same key from it, without running the action. The key holds the route, the URL, `Accept`, `x-data-transform`, the declared `vary` headers, the request's language and tenant, and the principal unless `scope` is `'tenant'` or `'shared'`. A request without an authenticated principal is not cached on a per-principal route; the warning says why. The policies run on every request. A reply that is not a 200 JSON answer, sets a cookie, says `no-store` or varies on `*` is never stored, nor the reply of a HEAD request on a GET route; a stored value is checked again before it is sent, and one that may not be sent is a miss. A wrong option fails at import with the name of the route. A `'tenant'` or `'shared'` route fails its registration when the route or its controller mounts a middleware that declares `static PerPrincipalReply = true`, as `AuthzFieldsMiddleware` does. A request whose `x-data-transform` names a transformer that declares it, as `AuthzFieldTransformer` does, runs uncached on every scope: a stored reply is replayed without the transformer. A route on which an inner middleware is mounted after `@ResponseCache` is never answered from the store, and its first request logs an error that names the middleware. Nothing is cached unless a route carries the decorator. `ResponseCacheMiddleware` mounted with `@Middleware()` fails its registration unless its options are exactly what `@ResponseCache` resolves. A reply that says `no-store`, as `@spinajs/authn-http` sets on every signed-in request, is not stored, and the route logs that once.
