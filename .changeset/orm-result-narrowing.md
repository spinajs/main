`populate('Relation')` with a literal relation name narrows the query result: a to-one relation's `Value` is typed as the related model (`Model | undefined` when the relation property is optional or typed `| undefined` / `| null`, because a missing row leaves it undefined) and a to-many relation as populated. The callback of such a `populate` is typed as a query on the related model. In strict mode (`OrmTypeRegistry.strictColumns`), `select`, `columns` and aggregates with a literal alias narrow the row to the selected columns; `count` aliases are typed `AggregateValue` (`number | string`), `sum`/`avg` aliases `AggregateValue | null`, and `min`/`max` aliases the column type or `null` (`Date | string | number` for a date column). New exports: `Projected`, `SourceRow`, `Rebox`, `Narrowed`, `StrictNarrowed`, `StrictAliasNarrowed`, `SelectNarrowed`, `StrictSelectAliasNarrowed`, `AggregateValue`, `MinMaxValue`, `Project`, `Reproject`, `PickColumns`, `ColumnTypeOf`, `PopulatePath`, `Head`, `Populated`, `RelationTarget`, `WithPopulated`, `PopulateName`, `PopulateTree`, `RelationLiteral` and `rel`. In strict mode `populate` rejects names that are not relations of the model, in string, array and object form; `rel(name)` passes a name computed at runtime.
