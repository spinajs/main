"@spinajs/client": minor

New subpath `@spinajs/client/mocks`: a zero-dependency runtime that generates mock data from JSON Schema as the server's Ajv validates it. `mockFrom(schemas, name, overrides?, { seed?, optional?, maxDepth?, formats? })` gives the same value for the same seed, honours types, `required`, `enum`/`const`, lengths in code points, number limits and `multipleOf`, `int32`/`int64`, array limits, tuples and `uniqueItems`, `$ref`, `allOf` (merged as the server merges closed members), `anyOf`, `oneOf` whose branches cannot overlap, every ajv-formats 2.1.1 format and `decimal`, and `pattern` for a regex subset (literals, classes, quantifiers, groups, alternation, anchors). `decimal` is sampled as plain digit text, which the server accepts whether or not it registers the format. `options.formats` plugs in a sampler per format, such as faker. A schema it cannot honour (`not`, `if`, `$data`, an unknown keyword, a pattern outside the subset without a usable `examples`, `default` or `const`, a schema the server's Ajv refuses) throws `MockUnsupported` (`MOCK001`), and `mockIssue` names the keyword. A mock never holds a key named `__proto__`, `constructor` or `prototype`, and never a non-finite number. Also `mockSchema`, `mockPage`, `mockCursorPage`, `createMockClient` (a method missing from the implementation rejects with `MockNotImplemented`, or resolves to mock data with `fallback: 'mock'`), `Rng` and `MockError`. The subpath imports nothing outside `@spinajs/client/formats`; a dependency-cruiser rule enforces it.
