`@spinajs/authz-orm`: ancestor links to a type that no `@Parent` names in the running process are never dropped. `authz:ancestors-rebuild` rewrites nothing and says which types (`--prune` deletes them, and the rows of a type no model declares); a write that would rewrite such rows fails with `AuthzConfigError` and rolls back; `authz:ancestors-verify` names them.
