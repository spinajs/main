`@spinajs/http-swagger` documents the answers of the route middlewares mounted on each route. `OpenApiBuilder` calls `documentation(route)` on every middleware `BaseController.MountedMiddlewares(method)` lists, in mount order: an answer is added under its status unless the JSDoc or `@Access` already set it, a later middleware wins over an earlier one (a route's own `@RateLimit` over its controller's), an answer with a `component` is registered once under `components.responses` and referred to, any other is inline (`schema`, or a named `type` resolved like `@response`), success `headers` go to the route's own inline 2xx responses, and `x-` extensions are copied onto the operation, arrays concatenated, any other key dropped; a key the operation already has (an `x-authz-*` of `@Access`) keeps its value unless both values are arrays. A middleware whose `documentation()` throws is left out of that route's operation with a warning naming the middleware and the route; the build goes on. A `@RateLimit` route therefore documents its 429: the shared `TooManyRequests` response by default, inline with `X-RateLimit-*` and an `x-rate-limit` extension when it sends the headers. `IOpenApiResponse` gains `headers`. A document built from the manifest (`system.manifest.mode`) sees no runtime middleware and has none of this.
