Server middlewares run on the same context hooks as route middlewares. `ServerMiddleware` extends `HttpMiddleware`: `onBefore(ctx)`, `onAfter(ctx)`, `onFinish(ctx)` and `onAround(ctx, proceed)`, plus `Order`, `isEnabled()` (called once at mount; `false` mounts nothing) and `handler()` (a third-party Express handler mounted at `Order`). Server middlewares are mounted in ascending `Order`, ties in DI registration order; only entered ones get `onAfter` (after the route's, in the exact reverse of entry) and `onFinish` (after the route's). `onBefore`/`onAround` get no route; `onAfter`/`onFinish` get `route`, `controller` and `path` when the request matched one. A `Response` returned from a server `onBefore` answers through the reply pipeline; a throw goes to the global error answer. `onBefore` may now return synchronously. Static files get `onFinish` only.

Breaking: `before()` and `after()` are deprecated; a subclass that overrides them is still mounted the 3.x way, with one warning per class, until the next major, and the base `before()` returns the hooks as one handler so `super.before()` keeps working. `req.storage` is created by `HttpServer` as its first handler, before `http.bodyLimits` and `http.middlewares`; `RequestStorage` is a deprecated no-op. `NotFoundMiddleware` and `ErrorHandlerMiddleware` are no longer server middlewares but the fixed tail of `HttpServer`, still replaceable with `DI.register(Mine).as(...)`: override `NotFoundMiddleware.reply(req)` and `ErrorHandlerMiddleware.reply(error, req)`; the 404 and the global error answer go through the reply pipeline. `__handle_error__` takes an optional reply function. `compression()` is removed from `defaultMiddlewares()`, so `http.compression.enabled: false` really turns compression off; `Compression` mounts through `handler()`. The shipped middlewares use the hooks: `CorsMiddleware` answers an allowed preflight with a 204 `Response` and takes its decision from the overridable `allowance(origin)`; `ThrottleMiddleware`, `SameOriginGuard` and `CsrfGuard` answer with a `Response` (bodies unchanged) and `refuse(reason, req)` now returns the `Response`; `CsrfGuard` steps aside through `isEnabled()`; `RealIp` parses its trust in `resolve()`; `ResponseTime` and `ServerTiming` set their headers in `onAfter` (not on static files or replies an action wrote itself); `AccessLog`, `SlowRequestWarning` and `PerfRollup` use `onFinish` (`AccessLog` logs aborted requests with `aborted: true` and has an overridable `shouldLog(ctx)`; the other two skip them; `PerfRollup` labels by the matched route's mounted path). New `RawJsonResponse` sends a JSON body as it is. `http.middlewares` handlers are logged by their function name.
