Saga compensation (D6). `ctx.step(name, fn, { compensate })` registers `compensate(result, ctx)` once the step succeeds. When the run fails (an unhandled error, `ctx.fail()` or the instance `timeout`), the instance goes `compensating` and the compensations run newest first, in the order the steps' results were journaled. Each is journaled as `compensate:<step>#<occurrence>` and retried under its step's retry policy; a backoff parks the instance `compensating` until it is due. The pass runs under the activation's lease, so a compensation longer than `workflow.leaseTtl` is not run a second time by another replica; after a crash the next owner replays `run()` to collect the compensations and resumes at the first one without a row. The instance ends `compensated` with the original `Reason` and `Error`, or `failed` with `Reason: 'compensation-failed'` and the original failure in `Error.details` (`original`, `originalReason`); `retry()` of such an instance resumes the pass and puts the original failure back. A compensation receives a `CompensationContext` (`instanceId`, `workflow`, `version`, `input`, `signal`, `log`) and cannot run durable operations. `cancel()` skips compensations unless `workflow.compensateOnCancel` is set; then the cancelled instance compensates and ends `cancelled`. A run failed with `non-determinism` is not compensated: the engine cannot tell which steps it took.
