New `@Idempotent()` route decorator (`required`, `ttl`, `fingerprint`, `maxReplyBytes`) and `parseIdempotencyKey()`. The decorator checks its options when the class is declared: it throws `InvalidArgument` when the argument is not an object, when an option is unknown or invalid, or when the decorator is put on a controller class. It records the options on the route as `IRoute.Idempotency` and does not change request handling yet. `parseIdempotencyKey()` accepts the `Idempotency-Key` value of draft-ietf-httpapi-idempotency-key-header in two forms, and both give the same key. One is a quoted string (`"k 1"`, printable ASCII with `\"` and `\\` escapes, no parameters). The other is bare visible ASCII without `,` and `;`. Either way the key is 1 to 255 characters. Each JSON reply that `jsonResponse` sends is captured internally (`CapturedJsonReply`: the status, `Content-Type`, `Location`, `ETag` and the exact JSON text), so the reply can be replayed later. Replies that do not pass through `jsonResponse` are not captured: files, buffers, redirects, templates and SSE.
