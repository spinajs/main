`ModelBase.audit(trail?)`, as a static and on a loaded row, with the `ModelAuditSource` port in `@spinajs/orm`; `@spinajs/audit-orm` implements it (`Model.audit().of(id)`, `.since(seq)`, `row.audit().entries()`). A model with its own member named `audit` must rename it. `pruneAudit()` deletes the events older than each trail's `retentionDays` on every connection that holds the trail's table, and once, for every source, for a trail with an archive (`archiveConnection`); `@spinajs/audit-orm/scheduler` adds `AuditRetentionTask` (`audit.retention`, daily, leader only). A trail or connection that fails does not stop the others: they are pruned, each failure is logged, then `AuditPruneFailed` gives the deleted count and every failure with its reason in its message, which is what a failed scheduler run keeps. Each trail owns its table: a table-store trail whose table another such trail uses is refused with `AuditConfigError` on write, read and retention, whatever their connections; the other trails keep working. When a model's connection is not the trail's, `Model.audit()` and `row.audit()` read both and merge by time; `since(seq)` above 0 then needs `query.source`. `auditSubjectId(key)` writes a row key as a subject id (composite keys as escaped parts joined with `:`, binary keys as hex) for producers and `row.audit()` alike.
