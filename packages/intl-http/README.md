# `@spinajs/intl-http`

Per-request language for `@spinajs/http`: detects the language from `?lang=`, a `lang` cookie or an `x-lang` header, stores it for `@spinajs/intl` and templates, and injects it into actions with `@Lang()`.

```sh
npm install @spinajs/intl-http
```
