# Schema DDL and reflection

The DDL the schema builder compiles to on PostgreSQL, the DDL this driver refuses, and how `tableInfo()` reads an existing table back into column descriptors. Migrations and `Orm`'s model bootstrap use both.

## How it works

1. **Build.** `driver.schema()` returns a `SchemaQueryBuilder`. `createTable()`, `alterTable()`, `createDatabase()`, `createView()` and the others build a query whose compiler comes from the driver's container.
2. **Columns.** `SqlTableQueryCompiler` (shared) resolves `ColumnQueryCompiler`, which is `PostgresColumnQueryCompiler`, once per column. It writes `"name" <type> [GENERATED BY DEFAULT AS IDENTITY] [COLLATE "x"] [NOT NULL] [DEFAULT ...] [CHECK (...)] [UNIQUE]`.
3. **Alter.** `SqlAlterTableQueryCompiler` (shared) resolves `AlterColumnQueryCompiler`, which is `PostgresAlterColumnQueryCompiler`, once per altered column, and prefixes each result with `ALTER TABLE "<table>" `. Each column alteration is its own statement.
4. **Send.** A multi-statement result is sent with `Promise.all`, one `executeOnDb()` per statement.
5. **Reflect.** At model registration, `Orm` calls `driver.tableInfo(table, Options.Database)`. `PostgresOrmDriver.tableInfo()` queries `information_schema` and returns `IColumnDescriptor[]`, or `null` when the table does not exist (a table without columns reads the same).

### Column types

`PostgresColumnQueryCompiler.typeExpression()`:

| Builder type | PostgreSQL type | Notes |
| --- | --- | --- |
| `string(name, n?)` | `VARCHAR(n)` | `n` defaults to `255`. |
| `text`, `tinytext`, `mediumtext`, `longtext` | `TEXT` | |
| `enum(name, values)` | `TEXT` plus `CHECK ("name" IN ('a','b'))` | Members are escaped string literals. |
| `set(name, values)` | `TEXT` | Stored comma-joined by `SqlSetConverter`; no `CHECK`. |
| `boolean` | `BOOLEAN` | A numeric default renders as `FALSE` / `TRUE`. |
| `tinyint`, `smallint` | `SMALLINT` | |
| `int`, `mediumint` | `INTEGER` | |
| `bigint` | `BIGINT` | |
| `float` | `REAL` | Precision arguments are ignored. |
| `double` | `DOUBLE PRECISION` | |
| `decimal(name, p?, s?)` | `NUMERIC(p,s)` | `p` defaults to `8`, `s` to `2`. |
| `binary`, `tinyblob`, `mediumblob`, `longblob` | `BYTEA` | Length arguments are ignored. |
| `uuid(name)` | `BYTEA` | Alias of `binary(name, 16)`, matching `UuidConverter`, which writes 16 bytes. Not the native `UUID` type. |
| `bit` | `BIT` | |
| `date` | `DATE` | |
| `time` | `TIME` | |
| `dateTime`, `timestamp` | `TIMESTAMPTZ(3)` | An instant; the session runs in UTC. |
| `json` | `JSONB` | |
| anything else | throws | `OrmException('type <type> is not supported by the postgres driver')` |

### Column modifiers

| Builder call | Output |
| --- | --- |
| `.autoIncrement()` on `int`, `smallint`, `tinyint`, `mediumint`, `bigint` | `GENERATED BY DEFAULT AS IDENTITY` |
| `.autoIncrement()` on any other type | throws `OrmException('postgres cannot auto-increment column <name>: identity requires an integer type, got <type>')` |
| `.collation('de-DE-x-icu')` | `COLLATE "de-DE-x-icu"` (quoted as an identifier) |
| `.caseSensitive()` | `COLLATE "C"`, unless `.collation()` names one |
| `.notNull()` | `NOT NULL` |
| `.default().value(0)` | `DEFAULT 0` (`DEFAULT FALSE` on a `boolean`) |
| `.default().date()` | `DEFAULT CURRENT_DATE` (`PostgresDefaultValueBuilder`) |
| `.default().dateTime()` | `DEFAULT CURRENT_TIMESTAMP` |
| `.default().raw(RawQuery.create('gen_random_uuid()'))` | `DEFAULT gen_random_uuid()` |
| `.unique()` | `UNIQUE` |
| `.unsigned()`, `.charset(...)`, `.comment(...)` | dropped: PostgreSQL has no column-level spelling |

### Altering a table

| Builder call | Statement |
| --- | --- |
| `alterTable('t', (t) => t.int('c'))` | `ALTER TABLE "t" ADD COLUMN "c" INTEGER` |
| `... t.int('c').after('b')` | `ALTER TABLE "t" ADD COLUMN "c" INTEGER`, and a `warn` log: the column is appended at the end |
| `... t.string('c', 128).notNull().modify()` | `ALTER TABLE "t" ALTER COLUMN "c" TYPE VARCHAR(128), ALTER COLUMN "c" SET NOT NULL, ALTER COLUMN "c" DROP DEFAULT` |
| `... t.boolean('c').notNull().default().value(1).modify()` | `... ALTER COLUMN "c" SET DEFAULT TRUE` |
| `... t.int('old').rename('new')` | `ALTER TABLE "t" RENAME COLUMN "old" TO "new"` |
| `alterTable('t', (t) => t.dropColumn('c'))` | `ALTER TABLE "t" DROP COLUMN "c"` |
| `alterTable('t', (t) => t.rename('t2'))` | `ALTER TABLE "t" RENAME TO "t2"` |

`modify()` keeps MySQL's `MODIFY` semantics: an attribute you do not restate is removed. Omitting `notNull()` drops `NOT NULL`; omitting a default drops the default.

### Databases, views and other DDL

| Builder call | Statement or result | Compiler |
| --- | --- | --- |
| `createDatabase('app').charset('UTF8')` | `CREATE DATABASE "app" ENCODING 'UTF8'` | `PostgresCreateDatabaseQueryCompiler` |
| `createDatabase('app').collation('de_DE.UTF-8')` | `CREATE DATABASE "app" LC_COLLATE 'de_DE.UTF-8'` | `PostgresCreateDatabaseQueryCompiler` |
| `createDatabase('app').ifNotExists()` | throws `NotSupported('postgres does not support CREATE DATABASE IF NOT EXISTS - check pg_database yourself before creating')` | `PostgresCreateDatabaseQueryCompiler` |
| `dropDatabase('app').ifExists()` | `DROP DATABASE IF EXISTS "app"` | shared `SqlDropDatabaseQueryCompiler` |
| `tableExists('users')` | `SELECT table_name FROM information_schema.tables WHERE table_name = ? AND table_schema = current_schema() LIMIT 1` | `PostgresTableExistsCompiler` |
| `tableExists('users', 'sales')` | same, with `table_schema = ?` bound to `'sales'` | `PostgresTableExistsCompiler` |
| `driver.truncate('users')` | `TRUNCATE TABLE "users"` | shared `SqlTruncateTableQueryCompiler` |
| `schema().lockTable('users')` inside a transaction | `LOCK TABLE "users" IN SHARE MODE` | `PostgresLockTableQueryCompiler` |
| `createView('v', (v) => v.orReplace().temporary().columns(['id']).security('INVOKER').checkOption('LOCAL').as(raw))` | `CREATE OR REPLACE TEMPORARY VIEW "v" ("id") WITH (security_invoker = true) AS ... WITH LOCAL CHECK OPTION` | `PostgresCreateViewCompiler` |
| `createView(...).security('DEFINER')` | `WITH (security_invoker = false)` | `PostgresCreateViewCompiler` |
| `createView(...).ifNotExists()` | throws `MethodNotImplemented('postgres does not support IF NOT EXISTS')` | `PostgresCreateViewCompiler` |
| `createView(...).algorithm('MERGE')` | throws `MethodNotImplemented` naming `ALGORITHM` | `PostgresCreateViewCompiler` |
| `dropView('v').ifExists()` | `DROP VIEW IF EXISTS "v"` | shared `SqlDropViewQueryCompiler` |
| `createEvent(...)`, `dropEvent(...)` | throws `MethodNotImplemented('orm-driver-postgres has no native scheduled events')` | `UnsupportedEventQueryCompiler`, `UnsupportedDropEventQueryCompiler` |
| `cloneTable(...)`, table history | fails resolving `TableCloneQueryCompiler` / `TableHistoryQueryCompiler`, which this driver does not register | none |

A view built from a select builder has its bindings inlined as PostgreSQL literals by `PostgresLiteralQuoter`: `WHERE "name" = 'it''s'`. `security_invoker` needs PostgreSQL 15 or later.

### Reflection: `tableInfo(name, schema?)`

1. **Schema.** `schema` is used only when it differs from `Options.Database`; otherwise the schema is `Options.Options.Schema`, else `public`. Callers written for MySQL pass the database name as the schema; this rule maps it to the connection's default schema.
2. **Columns.** `SELECT column_name, data_type, udt_name, is_nullable, column_default, is_identity FROM information_schema.columns WHERE table_name = ? AND table_schema = ? ORDER BY ordinal_position`.
3. **Missing table.** No rows: returns `null`, which lets migrations create the table.
4. **Constraints.** A second query joins `information_schema.table_constraints` and `key_column_usage` for the same table and schema.
5. **Descriptors.** One `IColumnDescriptor` per column, in table order:

| Field | Value |
| --- | --- |
| `Name` | `column_name` |
| `Type`, `NativeType` | `udt_name`: `int4`, `int8`, `varchar`, `text`, `numeric`, `bool`, `timestamp`, `jsonb`, ... |
| `Nullable` | `is_nullable = 'YES'` |
| `DefaultValue` | `column_default`, as PostgreSQL prints it (`nextval('users_id_seq'::regclass)`, `'draft'::text`) |
| `PrimaryKey` | the column is in a `PRIMARY KEY` constraint |
| `Unique` | the column is in a `UNIQUE` constraint, or is a primary key column |
| `AutoIncrement` | `is_identity = 'YES'`, or the default starts with `nextval(` (`SERIAL`) |
| `Schema` | the schema read |
| `MaxLength` | `-1` |
| `Comment` | `''` |
| `Unsigned`, `Uuid`, `IsForeignKey`, `Virtual`, `Aggregate`, `Ignore` | `false` |
| `ForeignKeyDescription`, `Converter` | `null` |

## Services and extension points

| Service | DI token and lifetime | Default implementation | Alternatives | How to replace or extend |
| --- | --- | --- | --- | --- |
| Column compiler | `ColumnQueryCompiler`, `@NewInstance()`, resolved per column with `[columnBuilder]` by the table and alter-column compilers | `PostgresColumnQueryCompiler` | `SqlColumnQueryCompiler` (MySQL) | Subclass; override `typeExpression()`, `defaultExpression()` / `_defaultCompiler()` or `compile()`. See [Customizing dialect compilers](07-customizing-dialect-compilers.md#store-timestamps-with-microseconds). |
| Alter-column compiler | `AlterColumnQueryCompiler`, `@NewInstance()`, `@Inject(Container)`, resolved per altered column with `[container, columnBuilder]` | `PostgresAlterColumnQueryCompiler` | `SqlAlterColumnQueryCompiler` (MySQL `MODIFY`) | Subclass; override `_add()`, `_modify()`, `_rename()` or `_columnDefinition()`. |
| Alter-table compiler | `AlterTableQueryCompiler`, `@NewInstance()` | shared `SqlAlterTableQueryCompiler` | | Subclass; override `compile()` or `_table()`. |
| Default value builder | `DefaultValueBuilder`, `@NewInstance()`, resolved per column with `[columnBuilder]` | `PostgresDefaultValueBuilder` | `SqlDefaultValueBuilder` (`CURRENT_DATE()`) | Subclass; override `date()`, `dateTime()`, `value()` or add methods. |
| Create-database compiler | `CreateDatabaseCompiler`, `@NewInstance()`, `@Inject(Container)` | `PostgresCreateDatabaseQueryCompiler` | `SqlCreateDatabaseQueryCompiler` (MySQL) | Subclass and override `compile()`. |
| Drop-database compiler | `DropDatabaseCompiler` | shared `SqlDropDatabaseQueryCompiler` | | Register your own class. |
| Table-exists compiler | `TableExistsCompiler`, `@NewInstance()`, resolved with `[builder]` | `PostgresTableExistsCompiler` | | Subclass and override `compile()`. |
| Truncate compiler | `TruncateTableQueryCompiler` | shared `SqlTruncateTableQueryCompiler` | | Register your own class, e.g. to add `RESTART IDENTITY CASCADE`. See the [example](07-customizing-dialect-compilers.md#reset-identities-on-truncate). |
| Recursive CTE compiler | `RecursiveQueryCompiler` | shared `SqlWithRecursiveCompiler` | | Register your own class. |
| View compiler | `CreateViewCompiler`, `@NewInstance()`, `@Inject(Container)` | `PostgresCreateViewCompiler` | | Subclass; override the [view hooks](../orm-sql/06-view-compiler-hooks.md). |
| Event compilers | `EventQueryCompiler`, `DropEventQueryCompiler` | `UnsupportedEventQueryCompiler`, `UnsupportedDropEventQueryCompiler` (throw) | | Register a working compiler, e.g. on `pg_cron`. See the [example](07-customizing-dialect-compilers.md#schedule-jobs-with-pg_cron). |
| Clone and history compilers | `TableCloneQueryCompiler`, `TableHistoryQueryCompiler` | not registered | `SqlTableCloneQueryCompiler` and the shared history compiler emit MySQL syntax | Register a PostgreSQL implementation in a driver subclass. |
| Reflection | `tableInfo(name, schema?)`, method of the driver | `PostgresOrmDriver.tableInfo()` | | Override in a [driver subclass](06-extending-the-driver.md), e.g. to fill `MaxLength`. |

## Important behaviour

- A `dateTime` / `timestamp` column is `TIMESTAMPTZ(3)`: it stores the instant, whatever zone wrote it, and keeps milliseconds. Because every session runs in UTC, `CAST(col AS TEXT)` reads `2026-10-19 12:00:00.123+00`. A value PostgreSQL stamps itself (`DEFAULT CURRENT_TIMESTAMP`) is rounded to the millisecond.
- `BY DEFAULT`, not `ALWAYS`: the identity column accepts explicit keys, which the batch insert path supplies for rows that have one. An explicit key does not advance the identity sequence; a later generated key can collide with it.
- `modify()` changes the type, `NOT NULL` and the default only. It does not add or remove `UNIQUE`, an enum's `CHECK`, an identity or a collation.
- `ALTER COLUMN ... TYPE` has no `USING` clause. PostgreSQL refuses a type change it cannot cast implicitly (`text` to `integer`); run that one with `schema().raw(...)`.
- The statements of one `alterTable()` call are sent in parallel. Outside a transaction they run on different pooled clients, in no guaranteed order.
- `tableInfo()` does not reflect foreign keys (`IsForeignKey` is always `false`), comments or `VARCHAR` lengths (`MaxLength` is `-1`).
- `tableExists()` without a schema checks `current_schema()`, the head of `search_path`. Set `Options.Schema` so it checks the schema your tables are created in.
- `CREATE DATABASE` cannot run inside a transaction. A migration that creates a database fails under `Migration.Transaction.Mode` `PerMigration` or `PerRun`.
- `ENCODING` accepts only names matching `[A-Za-z0-9_]+`; anything else throws `InvalidArgument`.

## Best practices

- Use `int`/`bigint` with `autoIncrement()` for surrogate keys; `GENERATED BY DEFAULT AS IDENTITY` is the PostgreSQL 10+ spelling and `tableInfo()` reports it as `AutoIncrement`.
- Restate every attribute you want to keep in a `modify()` call.
- Check for a database before creating it: `SELECT 1 FROM pg_database WHERE datname = ?` through `schema().raw()`.

## Patterns and antipatterns

```ts
// Don't: MODIFY semantics drop the NOT NULL and the default you did not restate
await driver.schema().alterTable('orders', (t) => {
  t.string('status', 32).modify();
});

// Do
await driver.schema().alterTable('orders', (t) => {
  t.string('status', 32).notNull().default().value('draft').modify();
});
```

```ts
// Don't: PostgreSQL has no CREATE DATABASE IF NOT EXISTS; this throws NotSupported
await driver.schema().createDatabase('reports').ifNotExists();

// Do
const found = await driver.schema().raw('SELECT 1 FROM pg_database WHERE datname = ?', ['reports']);
if ((found as unknown[]).length === 0) await driver.schema().createDatabase('reports');
```

## Examples

### Create the orders table of a shop

```ts sample
import { OrmMigration, OrmDriver, Migration, RawQuery } from '@spinajs/orm';

@Migration('main')
export class CreateOrders_2026_10_17_00_00_00 extends OrmMigration {
  public async up(connection: OrmDriver): Promise<void> {
    // "Id" INTEGER GENERATED BY DEFAULT AS IDENTITY NOT NULL, "Status" TEXT NOT NULL DEFAULT 'draft' CHECK (...),
    // "Total" NUMERIC(12,2) NOT NULL, "Meta" JSONB, "CreatedAt" TIMESTAMPTZ(3) DEFAULT CURRENT_TIMESTAMP, PRIMARY KEY ("Id")
    await connection.schema().createTable('orders', (table) => {
      table.int('Id').notNull().primaryKey().autoIncrement();
      table.enum('Status', ['draft', 'paid', 'shipped']).notNull().default().value('draft');
      table.decimal('Total', 12, 2).notNull();
      table.json('Meta');
      table.dateTime('CreatedAt').default().dateTime();
      table.string('PublicId', 36).notNull().unique().default().raw(RawQuery.create('gen_random_uuid()::text'));
    });
  }

  public async down(connection: OrmDriver): Promise<void> {
    await connection.schema().dropTable('orders');
  }
}
```

### Widen a column without losing its constraints

```ts sample
import { OrmMigration, OrmDriver, Migration } from '@spinajs/orm';

@Migration('main')
export class WidenCustomerEmail_2026_10_17_01_00_00 extends OrmMigration {
  public async up(connection: OrmDriver): Promise<void> {
    // ALTER TABLE "customers" ALTER COLUMN "Email" TYPE VARCHAR(320),
    //   ALTER COLUMN "Email" SET NOT NULL, ALTER COLUMN "Email" DROP DEFAULT
    await connection.schema().alterTable('customers', (table) => {
      table.string('Email', 320).notNull().modify();
    });
  }

  public async down(connection: OrmDriver): Promise<void> {
    await connection.schema().alterTable('customers', (table) => {
      table.string('Email', 255).notNull().modify();
    });
  }
}
```

### List the identity columns of a table

```ts sample
import { DI } from '@spinajs/di';
import { Orm } from '@spinajs/orm';

export async function identityColumns(table: string): Promise<string[]> {
  const orm = await DI.resolve(Orm);
  const driver = orm.Connections.get('main')!;

  // reads Options.Schema, or public, when no schema is passed
  const columns = await driver.tableInfo(table);
  return (columns ?? []).filter((c) => c.AutoIncrement).map((c) => c.Name);
}
```
