# RA14-2: teams final-review fixes

Status: proposed (final review, 2026-10-15).

## Problem

- An invitation is judged by a dry run when it is created and executed as SYSTEM when it is accepted, so it outlived
  the inviter's authority: an inviter demoted or removed later still granted the role (review decision 3).

## Change

- `INVITATION_REFUSALS` gains `inviter_lost_authority`. `InvitationService.accept` judges the inviter (`created_by`)
  again before it grants: `team:invitations.manage` at the team and the same AuthzAdmin dry run as `create`. A
  refusal there is `InvitationRefused('inviter_lost_authority')`; teams-http answers it 403
  (`invitation_inviter_lost_authority`).

## Affected lanes

- L15 (teams-http) maps the new code.
